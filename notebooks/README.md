# notebooks

データを調べる（EDA）ためのノートブックを置く場所。開き方（カーネルの選び方）はリポジトリ直下の README の「ノートブック」を参照。

## 最初の EDA

1 つのノートブックを 1 人が担当し、先頭に書いてある「対象のカラム」を可視化・分析する。全カラムがどれか 1 つのノートブックに入っている。データの読み込みまでは済ませてある。

| ノートブック | 対象のカラム |
|---|---|
| `eda_1_location.ipynb` | 場所：市区町村コード、市区町村名、地区名、最寄駅：名称、最寄駅：距離（分） |
| `eda_2_property.ipynb` | 物件：間取り、面積（㎡）、建築年、建物の構造、改装 |
| `eda_3_zoning.ipynb` | 用途と都市計画：用途、今後の利用目的、都市計画、建ぺい率（％）、容積率（％） |
| `eda_4_transaction.ipynb` | 取引：取引価格（総額）、取引時期、価格情報区分、取引の事情等 |

まずは各カラムそのもの（分布、値の種類、欠損、変わった値、train と test の違いなど）を見る。カラムどうしや価格との関係は、その後で。

## ルール

- 他の人のノートブックは編集しない（ノートブックは git で衝突すると直すのが大変なため）
- 新しく調べたいことは `<名前>_<テーマ>.ipynb` で新しく作る
- 出力（グラフ）は残したままコミットする
- 分かったことは Issue に書く

## eda_utils.py

```python
from eda_utils import TARGET, load, setup_plot

setup_plot()  # グラフで日本語が表示されるようにする
train, test = load()  # train と test を元の値のまま読み込む
```

数値への変換（「戦前」「30分～60分」「2,000㎡以上」などの扱い）や㎡単価などは、各ノートブックで必要に応じて作る。良い変換が見つかったら、モデルの前処理に PR で入れる。
