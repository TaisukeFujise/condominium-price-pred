# 演習1 コンペ：東京都の中古マンション等の取引価格予測

## 課題

東京都内の中古マンション等の取引について、物件と取引の情報から **取引価格（総額）** を予測してください。

- 学習データ：2019年第1四半期〜2025年第2四半期の取引
- テストデータ：2025年第3四半期〜2026年第1四半期の取引（価格は伏せてあります）

## ファイル

| ファイル | 内容 |
|---|---|
| `train.csv` | 学習データ（202,323件）。目的変数 `取引価格（総額）` を含む |
| `test.csv` | テストデータ（29,341件）。`取引価格（総額）` 以外の列 |
| `sample_submission.csv` | 提出形式の例（`id, price`。`price` に予測した取引価格（総額、円）を入れる） |

## 列

| 列 | 内容 |
|---|---|
| `id` | 行の識別子 |
| `価格情報区分` | 不動産取引価格情報／成約価格情報 |
| `市区町村コード`, `市区町村名`, `地区名` | 所在地 |
| `最寄駅：名称`, `最寄駅：距離（分）` | 最寄駅と徒歩時間 |
| `取引価格（総額）` | 目的変数（円）。train のみ |
| `間取り`, `面積（㎡）`, `建築年`, `建物の構造` | 物件の情報 |
| `用途`, `今後の利用目的` | 用途 |
| `都市計画`, `建ぺい率（％）`, `容積率（％）` | 都市計画上の情報 |
| `取引時期` | 四半期単位 |
| `改装`, `取引の事情等` | その他 |

値はすべて元データの表記のままです。前処理の方針もグループで決めてください。

## 評価

RMSLE（予測価格と実際の価格の対数の差の二乗平均平方根）。値が小さいほど良い。

## ルール

- **テスト期間（2025年第3四半期以降）の取引データを、外部から取得・参照することを禁止します。** 人が手作業で行う場合も、コーディングエージェントなどのAIが自動で行う場合も同じです。グループの指示ファイル（CLAUDE.md・AGENTS.md 等）にもこのルールを明記してください。
- 上位グループには、コードの提出を求めることがあります。現実的な水準を大きく超えるスコアは確認の対象になります。

## 出典

出典：国土交通省 不動産情報ライブラリ（https://www.reinfolib.mlit.go.jp/）の不動産価格（取引価格・成約価格）情報をもとに、講義用に加工して作成（東京都・中古マンション等、2026年10月6日取得）。加工内容：全行同じ値の列（種類、都道府県名）の削除、行の並べ替えと `id` の付与、学習用とテスト用への分割。
